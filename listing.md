# maskline

- Repository: https://github.com/EngineeringErgonomics/maskline
- Description: An MCP server that scans AI agent transcripts and build logs for leaked secrets, including shell-trace lines, and returns a redacted copy with a plain report. It cuts exposure from pasted logs and saves reviewers manual checks before sharing.
- Tags: secrets, redaction, transcripts, build-logs, mcp-server, agent-safety
